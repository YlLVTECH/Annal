有无相生

天地万物生于有，有生于无。这款笔记自「无」而起 —— 没有数据库，没有云端，没有框架的负累。

每一篇笔记，只是磁盘上一个干干净净的 Markdown 文件；应用本身，不过一层 TypeScript 的形、一副 Rust 的骨、一座 Tauri 的桥。形散而骨立，桥通则神全。

  • 零数据库
  • 零云端依赖
  • 一一篇 · 一文件
一

道生一

一篇一文件

落笔成章。

标题取自正文第一行，磁盘文件名随之同步改名；非法字符自动清理，重名自动追加序号，绝不覆盖已有文件。

输入停顿五百毫秒便已落盘；关闭窗口时，未干的墨迹也会被温柔冲刷保存 —— 不丢一字。

  • 每篇笔记一个独立 .md 文件，位置由你选择
  • 文件名与笔记标题始终一致
  • 防抖 500ms 自动保存，关窗自动冲刷
  • 元信息仅入索引，正文永在明处

一生二

阴阳相抱

点太极 · 换阴阳

明为阳，暗为阴。

宣纸之上走墨为阳，碑拓之内观字为阴。一键切换（页面右上角亦可），气质顿殊，选择会被记住。

编与览。

编辑与预览同屏相照，滚动位置相随；预览中的外链点击之后，交由系统浏览器承接，不染尘埃。

三生万物

功用自生

壹

版本历史

git 式线性历史，显式提交；内容寻址 blob 存储，同文共享一份，4KB 以上 zlib 压缩。

贰

版本对比

行级 diff，任意版本两两对照；恢复旧版如 checkout，再提交以留痕。

叁

Markdown 全语法

GFM 表格、任务列表、代码块高亮、删除线；工具栏一键插入常用语法。

肆

外部文件

对话框多选、拖放入窗、双击 .md 关联打开；原地读写，亦可另存为笔记。

伍

快捷键

Ctrl+N 新建　Ctrl+O 打开
Ctrl+S 保存　Ctrl+B 粗体
Ctrl+I 斜体　Ctrl+K 链接

陆

字数与滚动

状态栏字数统计常驻；分屏视图滚动同步；工具栏随窄窗自动换行。

柒

安全渲染

DOMPurify 白名单过滤；预览外链由系统浏览器打开；本地图片经 asset 协议加载。

捌

单实例与冲刷

再次打开文件，回到已运行的窗口；关闭前未保存内容自动落盘，片字不丢。
